
# PrepAI – GenAI Interview Preparation Platform

PrepAI is a Generative AI-powered interview preparation platform that generates personalized technical and behavioral interview preparation plans using a user's resume, self-description, and job description.

The platform uses Google Gemini AI to analyze candidate profiles and generate role-specific interview questions, preparation roadmaps, and skill improvement suggestions.

---

##  Features

- AI-powered interview preparation
- Resume & Job Description analysis
- Personalized technical questions
- Behavioral interview question generation
- Skill-gap analysis
- Customized preparation roadmap
- Responsive full stack web application

---

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Google Gemini AI API
- Tailwind CSS

---

##  AI Functionality

- Resume understanding using LLMs
- Prompt engineering with Gemini AI
- Dynamic interview question generation
- AI-based preparation recommendations
- Personalized learning suggestions
